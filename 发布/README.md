# 古风倒计时 v1.10

一个常驻 Windows 桌面的倒计时小工具。宣纸底、古铜框、朱砂印，剩余时间越少，颜色越紧迫。

纯 Python 标准库 + Tkinter 实现，**零第三方依赖**；发布包是打包好的单文件 exe，
**没有 Python 也能直接跑**。压缩包里只有四个文件，免安装。

| 文件 | 说明 |
|---|---|
| `古风倒计时.exe` | 主程序，双击就能用（首次启动慢两三秒是自解压，正常） |
| `使用说明.md` | 完整使用文档：时间格式、颜色规则、窗口操作、传书、定时关机、窗口盯守、远程设置、常见问题 |
| `mailer.pyw` | 传书使者 —— 独立发信小程序，被主程序按需唤起，发完即退 |
| `默认配置.json` | 远程设置模板：可以直接上传到你的网址，各台机器定时取回；也可以在各机器上「从文件导入」。里面是适合各机器统一的出厂设置，`shutdown.at`（关机时刻）留空待填 |

> **程序不会在文件夹里生成任何文件。** 目标时刻、窗口位置、传书设置、
> **邮箱授权码**、寄信履历、定时关机的网址、盯守的进度，全部存在你自己的用户目录下：
>
> ```
> C:\Users\你的用户名\.古风倒计时\设置.json
> ```
>
> （按 `Win + R`，粘贴 `%USERPROFILE%\.古风倒计时` 回车就能打开，记事本能看能改。）
> 所以这个文件夹里**永远只有这四个文件** —— 不会多出 config、日志、缓存之类的东西。
> 授权码在那个文件里是**加密**的，拷到别的电脑解不开；设置面板底部的
> 「恢复出厂」可以一键清空。

## 怎么开始

1. 双击 `古风倒计时.exe`，窗口出现在屏幕右上方
2. 双击窗口（或右键 → 设置）填目标时刻，例如 `10.1`
3. 想收邮件提醒、定时关机、盯窗口，都在设置面板里，分左右两列；
   面板**右下角可以拖着改大小**（拖乱了点标题栏的「⤢」复位），每一项的详细说明见 `使用说明.md`

## 主要功能

- **桌面挂件形态** —— 不占任务栏，默认置顶；可拖动、可 8 方向自由缩放，数字字号自动适配
- **任意分隔符的时间输入** —— `10.1`、`10月1日11:30`、`10-1 11:30` 都能认；写错了会明确告诉你错在哪
- **一键 +30 天** —— 右键菜单第一项、设置面板各有一个按钮，点一下倒计时顺延 30 天：
  没过期在原时刻上加，过期了从现在起算；归零那一刻目标会被钉成带年份的写法，
  **重启多少次都停在「時辰已到」**，不会再变成三百多天
- **颜色随紧迫度变化** —— 竹青 → 琥珀 → 朱砂 → 入夜，最后 12 小时连底色一起换成墨黑
- **传书 · 邮件提醒** —— 剩余时间跨过档位时自动寄一封邮件；失败退避重试、关机期间错过的开机补寄、同档只寄一次
- **定时关机** —— 三个触发来源，**谁先到谁关**：① 远程设置那份配置文件里写死的 `shutdown.at`（写法同目标时刻，各台机器定时取回就排上，只维护一份文件）；② 从你自己的网址上取回的时刻（`10.1.11.30`、`2026-10-01 11:30`、JSON 字段、网页标签、时间戳都认）；③ 倒计时目标归零那一刻（默认开，可关）。
  三个时刻始终各自独立，取一次日期绝不会动你设的倒计时。到点先弹窗问一句（默认 60 秒，不点才关），关不掉每分钟自动重试直到关成；程序没运行期间错过的不补关
- **窗口盯守** —— 定时查看某扇窗口还在不在（默认 30 分钟一次），不见了先弹窗问一句「是你自己关的吗」，
  **问话期间继续核实：它一出现就当场撤销，一封信都不寄；连续不见满设定时间（默认 10 分钟）才寄**；
  机器重启过会推回「等它出现」，开机不会误报；窗口下次出现时自动接着盯。
  面板上有「试一遍」按钮，可当场演一遍并真发一封标注为「演练」的信
- **远程设置** —— 把导出的那份 `共用设置.json` 放到一个网址上，每台机器自己去取
  （启动后 20 秒、之后每 6 小时一次），认证支持用户名密码 / 令牌 / 自定义请求头 / 无。
  **密码类永不参与同步**：授权码不在可同步清单里，远端也改不了"下次去哪儿取"和开机自启；
  **邮件服务商（服务器与端口）默认也不给改** —— 授权码是绑在服务商上的，
  这一项要同步得在清单里显式勾上
- **在线升级** —— 设置面板点「检查更新」自动换新（sha256 校验、失败回滚、数据无损）
- **恢复出厂 / 一键清理** —— 设置面板一键清空数据，卸载送人无残留
- **单实例 + 开机自启** —— 重复双击只会把窗口拉回屏幕；自启写在当前用户启动项，无需管理员权限
- **极低占用** —— 实测 CPU 0.014%、内存约 38 MB、GPU 0%，每秒刷新仅 2.2 ms

仅支持 Windows。
